Before you download

SoW:CE is a free, unofficial mod for Middle-earth: Shadow of War. It's experimental and it changes how the game runs, so please read this page before you install it. When you've read it, tick the boxes at the bottom and the download will unlock.

Disclaimer

These are the real risks of using SoW:CE. If you aren't comfortable with them, don't install it.

  1. It's experimental. SoW:CE is a highly experimental framework that changes Shadow of War while the game is running. It can crash or freeze the game, break quests, damage or lose saves, and leave your army or progress in a state that can't be undone. Some features have only been tested on a handful of PCs.
  2. Online services haven't been tested with mods. That means Online Vendettas, Online Conquests, online fight pits, leaderboards and anything else that talks to WB's servers. If you use them with SoW:CE, you do so at your own risk. Nobody can say how those servers will respond to a modded game, or what will happen to your WB or Steam account as a result.
  3. Garrison and the Market may not load or work properly. Both rely on WB's servers and on parts of the game that were changed or switched off years ago. They can fail to load, show the wrong content or stop working at any time. Nothing you open, earn or buy through them is guaranteed.
  4. It changes your game install. The setup adds its own files to the game folder, including a loader in the x64 folder. If you install the optional Armory weapons, it also changes two of the game's own files, hotchunk.arch06 and x64\default.archcfg. Uninstalling normally puts them back. If another mod changed them in the meantime they're left alone, and Steam's Verify integrity has to restore them.
  5. Your saves are at risk. Some things you do with the menu get written into your save, and uninstalling SoW:CE doesn't undo them. A save that holds an Armory weapon hasn't been tested without them. SoW:CE backs up your saves when the game starts, but don't rely on that alone. Keep your own copies.
  6. Mods can clash. Other mods and tools can conflict with SoW:CE, and nobody has tested every combination.

Remove it before you update

Before any Windows update, graphics driver update or Shadow of War update, do a clean remove. This makes sure nothing of SoW:CE's is in the way of the game's DRM. One tester's game asked to be activated again after a Windows update, and SoW:CE is built for Steam version 1.21 only, so a game update can break it too.

  1. Close the game.
  2. Run the setup, click Uninstall at the bottom of the window, tick "Also delete my mod menu settings and logs" and confirm.
  3. In Steam, right-click Shadow of War, open Properties, then Installed Files, and click Verify integrity of game files.
  4. Install the update, then start the game once from Steam to check it still runs.
  5. Run the setup again to reinstall SoW:CE.

Keep the setup file so you can do this later. If Windows updates on its own and the game won't start or asks to be activated, do the same thing: clean remove first, get the game running by itself, then reinstall.
