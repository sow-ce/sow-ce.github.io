AIRE — AI Reverse Engine (aire/)

Autonomous AI-native RE infrastructure. Full pipeline from live memory to a complete engine model, plus on-disk format analysis. There is NO CLI — AIRE is driven exclusively by AI via aire.headless.call() (the Cortex Python API underneath is for AIRE-internal module code).
