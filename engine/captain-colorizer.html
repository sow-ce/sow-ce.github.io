Character tint — the colours the engine APPLIED (MEASURED 2026-10-06, code + live)

The .mat tint constants are mostly placeholders (white = no-op, magenta (1,0,1) = unset; real colours only on skin / eye / warg materials of one Minas Ithil capture). Each character's real colours:

CChar+0x2340 -> visual object (vt 0x1DA9610)                  12/12 characters
  +0xB8 SMC: +0x28 23 piece slots (Model/SimpleModelPieces), +0xE0 15 ArmorData slots,
             +0x178 u32[16] ARGB, alpha 0xFF = set / 0x00 = unset (142 chars: only 0/FF)
  +0xC0 tint owner: +0x18/+0x20 vector of 0x18-byte entries
             {+0 SimpleModelTint, +8 ArmorData (0 = base), +0x10 handle}
handle vt 0x1DC47B8 +8 -> {+0 begin, +8 end}: records
             {u32 tag<<28 | P919(name) & 0x0FFFFFFF, u32 size, data}, tag 2 float3, 5 float
  • Colour slots (named by SimpleModelTint channel indices): 0 skin, 1 eye, 2 hair, 3 tattoo, 4 warpaint, 5 metal, 6 leather, 7 cloth, 8 bone, 9 trim, 10-15 faction metal / leather / cloth / bone / trim / warpaint; 16 = channel unused. docs/FACTION_COLOR_RE.md (8 = "Clothing2", faction slots "always 0") is wrong: faction cloth (12) is set on 75 of 142 characters. tools/re/orc_forge.py's SMC_COLOR_DIRTY 0x1A0 is slot 10, not a flag.
  • Writer: 0x36B430 (per SMC slot with SimpleModelPieces.Tint) -> 0x4C3634 (find/create entry) -> 0x2EAD20 (per R/G/B/A channel with index < 16) -> 0x2EAF10 (slot 1 = head: tattoo / warpaint gated by SimpleModel.TattooApplyToHead / PaintApplyToHead) -> 0x2EAFF4: amount = 1.0 (0x202E5A0) if alpha == 0xFF else 0.0, colour = RGB x 1/255 (0x202E8C0). Second writer 0x36B5D8 -> 0x4C3F58 -> 0x78CD3C: colours overridden by the slot's ArmorData (Player/SauronFollowerColorOverrides, HSV-rolled), entry keyed on the ArmorData. Selection = 0x4C3634: an entry whose +8 is the slot's ArmorData wins, else the base entry. Slot -> ArmorData index = inverse of 0x36B700. [[X+0xC0]+8] = the character's Model/SimpleModel.
  • Join: piece +0x80 Model record == the slot's SimpleModelPieces.Model (pointer equality). Reading the HANDLE covers both writers, the HSV roll included. 252 slots / 0 bad handles.
  • Shader (body_lod0.fxo PS, disassembled): c = lerp(c, diffuse * tint_ch, mask_ch * amount_ch) for R, G, B, A, the target always from the ORIGINAL diffuse; alpha untouched; no manual gamma. The blend runs in LINEAR space: the DXGI byte in the .tex header is UNORM, but texture creation (0x1E71F0) takes typeless / UNORM / sRGB triplets from the format table 0x2777E20 (built by 0xD7590) and the TEXR header carries an sRGB FLAG (character variant: 19 bytes after the path; 1 on _d, 0 on _n / _s / _m, two texture sets). The bake linearises the diffuse, blends with the linear mask and the byte/255 tint, re-encodes sRGB.
  • Normal maps (tNormalMap): X in GREEN, Y in ALPHA - NOT the textbook DXT5nm order (CORRECTED 2026-10-06; the first export and the weapon-texture note had them swapped). The body PS decodes n = (G*2-1, A*2-1, z) and multiplies X by the skinned TANGENT, Y by the BINORMAL (its VS writes the rows of [T B N] to TEXCOORD2..4). Confirmed on the textures with a CURL ORACLE (a normal map is a height gradient, so the right assignment is curl-free): X=G, Y=A wins 58/60 captured maps (relative curl 0.663 vs 0.749 swapped, 0.85-0.87 sign-flipped). Y follows +v (image down): 99% of stored binormals follow +dP/dv on non-mirrored meshes (orc bodies 50/50: mirrored UV islands). glTF gets (G, -A, z); the geometry mirror needs nothing extra. textures.normal_curl() is the oracle, normal_to_gltf() the conversion.
  • Specular (tSpecularMap, linear): R = reflectance (every dielectric 167-173; the material default k_v?SpecularTint is (0.6667 = 170/255, 1.0, 0.5); polished metal 240-255), G = a mask (255 except hair / feathers; unknown), B = ROUGHNESS (tear film 27, eyes 41, ring 50, cloth 207-228). The shader lerps the texel toward each tint channel's k_v?SpecularTint by mask x k_f?TintAmount x k_f?SpecularTintAmount x k_fSpecularTintToggle (cb3[24..28]), the RUNNING value each step; the tint handles carry these too. Exported as glTF metallicRoughness: roughness = B / 255, metallic = (R - 170) / 85 (approximate: the engine's lighting pass is not decoded).
  • Not covered: pieces outside the 23 SMC slots (attachments: 0x36B430's second loop over X+0x88, tint record at [obj+0x20]+0x1B8) and weapons keep the shipped constants, magenta off. Talion's array is empty.
