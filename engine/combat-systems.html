Cooldown System (CRACKED + IN-GAME PROVEN 2026-08-19)

A cooldown is one latched u32 ABSOLUTE END-TIME — nothing ticks. CheckCooldown (0x493320) returns [obj+0x10] - now floored at 0. StartCooldown (0x1A78B34) rolls rand(MinTime..MaxTime) through the StatValueOption evaluator (0x30F42C) at start time, scales by 170.0 ticks/sec (0x202E64C), stores now + ticks — so duration edits apply on the NEXT use with no reload. Time source 0xF23310: Combat/Cooldown.TimerType (obj+0x14) selects one of 4 global clocks (0x2702550/0x2702598/0x2702590/0x2702548, case 0-3; time = *(*(clock)+8)+0x18). Debug channel "[COMBAT|COOLDOWN|C]: " gated on byte 0x2A34D57.

Every combat character owns a PARALLEL-ARRAY cooldown table (start path 0xF13920 indexes it as (rec - cat->rec_array)/0x28, primaries /0x20 — not a hash map):

table+0x00 slots (stride 0x20)   +0x08 count (356 = the whole category)   +0x10 category ptr
slot+0x00 record key   +0x08 record   +0x18 END TIME u32   +0x1C clock id

Measured live: 33 tables, 356/356 keyed on every one, 872 active timers coherent. Player chain (all reads, re-resolved every pass): [[base+0x2A34C68]] (player list, entry 0 -> player entity; the slot was long misnamed NemesisManager) -> +0x26A8 component (same offset as the level getter) -> +0x5A0 table. Identity-check [table+0x10] == the live Combat/Cooldown category ptr before any write, and the slot KEY before each slot write.

No Cooldowns = zero slot+0x18 in the PLAYER's table — player-only BY CONSTRUCTION (the table is per-character), covers ALL drivers, no hook, no revert needed (timers re-arm on next use). Driver census of the 356 records: 342 raw / 8 formula / 6 variable — the formula ones are exactly the summon wheel (PC_Summon_Mount(_Troll/_FellBeast) via MountCoolDown, PC_Summon_Faction + PLBar_Summon_Faction_Slot_0/1/2 via FollowerCoolDown), so the old config route (zero RawValue, skip formula/variable) structurally missed the most visible cooldowns, and the removed 0x493320 detour stuttered because Hooks::Install ran lazily inside SetEnabled (MinHook enable freezes every thread).

C++: sdk/sow_cooldown_live.hpp (Resolve / ClearSlot / ClearAll / Live clearer at 4 Hz, pauses on GameDB canary loss; MinTime/MaxTime editing in seconds, ledgered) + ui/tabs/sow_cooldown_editor.hpp (Combat > Damage & Skills > "Combat - Cooldowns (Live)"). state.noCooldowns has ONE owner: ApplyActiveCheats.
