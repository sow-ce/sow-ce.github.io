How Shadow of War works inside

A technical reference to the engine behind Middle-earth: Shadow of War: how the executable is organised, how the game streams, stores and renders its world, and how its AI, combat, animation and Nemesis systems work.

Everything here was established by reverse engineering the Steam release (game version 1.21): static analysis of the executable, inspection of the running game's memory, and parsing of the shipped archives. Code locations are given as offsets from the image base 0x140000000, so they apply to every run of that build. The GOG and Microsoft Store builds run the same engine, data formats and object layouts at other addresses: Game builds compares the three. Questions that remain open are listed at the end of each chapter.
