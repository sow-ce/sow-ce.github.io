Shadow of WarCommunity Edition

A mod menu for Middle-earth: Shadow of War on Steam (game version 1.21). Install it with the setup, then press TAB in game to open it.

Patch notes

What this mod menu includes

Everything here is in v1.392 and has been tested in game. It's grouped the same way as the menu's tabs, and each entry shows where to find it.

    How to install

    1. Download the setup, .
    2. Close the game, then run the setup. It finds your Steam install on its own.
    3. Click Install, start the game from Steam, and press TAB.

    Later on, the same setup handles updates, repairs and uninstalling.

    You'll need

    • Windows 10 or 11 (64-bit)
    • Middle-earth: Shadow of War on Steam, game version 1.21
    • The Visual C++ x64 runtime (the setup tells you if it's missing)
    • On Windows N or KN editions, the Media Feature Pack

    FAQ

    Which version of the game does it work with?

    The Steam version, game version 1.21, on 64-bit Windows 10 or 11. Other versions won't work. The setup checks your game before it changes anything.

    How do I open the menu?

    Press TAB in game. Inside the menu, Ctrl+F searches every panel.

    Will it mess with my save?

    Most of it only lasts while the game is running. Things you change in the world, like moving a captain or bringing one back, get saved the same as anything else you do in game. Your saves are also backed up every time the game starts, and the setup can restore any of those backups.

    Why do my mods turn off when I restart?

    That's on purpose, so a bad setting can't follow you into the next launch. If you want them to stay on, turn on "Remember mods between launches" under Settings > Mods & Startup.

    Windows says the setup might be unsafe

    The setup isn't code-signed, so SmartScreen warns about it. Only download it from here or the GitHub release. If you want, check its SHA-256 against the one above, then click More info and Run anyway.

    Does it work with other mods?

    Packet mods work, and the setup can convert them into archive mods. Anything else that loads through winhttp.dll has to be removed first. The setup will tell you if it finds one.

    How do I update or uninstall?

    Run the newest setup and click Update. Uninstall is at the bottom of the setup window. If you use Steam's "Verify integrity", run the setup again afterwards to get the Armory weapons back.

    Something broke. What do I send you?

    In the setup, click "Report a problem". It saves a zip with your logs.
